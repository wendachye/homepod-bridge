# HomePod Bridge 0.12.5rc1

This is a Windows release candidate, not a validated production release.
It captures Windows system audio and streams it to selected HomePods.

## Speaker selection

Select each speaker entry you want to play through. To target both members
of a HomePod stereo pair, select both entries. Automatic forwarding to the
whole pair from a single selection is unsupported and excluded from this
release's scope. Multiple selections use independent streams; audible echo
or drift remains possible and synchronization validation is incomplete.

## Changes

- Correct native HomePod clock initialization when Sync/Follow_Up packets
  arrive without a Delay_Req response; retain updates across setup and playback.
- Include encrypted control-channel framing, bounded discovery, live PCM
  resampling and PTP packet fixes, plus capture and reconnect improvements.
- Package the Windows runtime, native helper, license notices and complete
  corresponding native source with offline build instructions.

## Validation

The clock-corrected native source passed 987 unique tests, including four
optional audio/network tests. The preceding diagnostic EXE passed a clean
Windows Sandbox runtime and tray lifecycle check without Python installed.
Those results are not a substitute for checking this final candidate.

Final candidate CI, artifact hashes and smoke reports are recorded with the
release assets. Remaining production validation includes two-speaker
synchronization, eight-hour audible playback across a WAV rollover,
silence/resumption, controlled loss and recovery, sleep/resume, and the
remaining interactive Windows checks. See the
[release checklist](../release-validation.md) and
[hardware record](../windows-validation-2026-09-17.md).

## Files

- `HomePodBridge.exe`: Windows x64 app; no separate Python installation needed.
- `homepod_bridge-0.12.5rc1-py3-none-any.whl`: Python package; does not bundle
  the native helper.
- `HomePodSender-source.zip`: corresponding native helper source and dependencies.
- `COPYING-HomePodSender.txt` and `THIRD_PARTY_NOTICES.md`: native license notices.
- `SHA256SUMS.txt`: release asset checksums.

Keep the native license notices and corresponding source available alongside
the EXE. The app captures the current default stereo Windows output; it does
not mute the PC speakers. Quit an older running copy before launching this
candidate. Saved device selections and volumes are reused.
